# Sprint 6 - Автотесты для сервиса «Яндекс.Самокат»

## Описание проекта

Проект содержит автотесты для учебного сервиса «Яндекс.Самокат» (https://qa-scooter.praktikum-services.ru/).

Тестирование выполнено с использованием **Selenium** и **Python (pytest)** с применением паттерна **Page Object Model**.

---

## Что тестируется

### 1. Вопросы о важном (FAQ)
- Проверка раскрытия ответов на вопросы
- 8 вопросов в разделе «Вопросы о важном»

### 2. Заказ самоката
- Оформление заказа через кнопку «Заказать» в хедере
- Оформление заказа через кнопку «Заказать» внизу страницы
- Проверка успешного создания заказа
- Получение номера заказа
- Переход на страницу статуса заказа

### 3. Логотипы
- Переход на главную страницу по клику на логотип «Самоката»
- Открытие страницы Дзена в новой вкладке по клику на логотип Яндекса
